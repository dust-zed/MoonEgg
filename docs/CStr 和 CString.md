`CStr` 和 `str`的对应关系如下：
| 类型 | 用途 | 是否拥有数据 | 内容约束 |
|---|---|---|---|
| `&str` | 借用 Rust 字符串 | 否 | 必须是合法 UTF-8 |
| `String` | 拥有 Rust 字符串 | 是 | 必须是合法 UTF-8 |
| `&CStr` | 借用 C 字符串 | 否 | 以零字节结尾，内部没有零字节 |
| `CString` | 拥有 C 字符串 | 是 | 同上，但不保证 UTF-8 |

所以，`&CStr` 对应 `CString`,就像 `&str` 对应 `String`。`CStr`和`str`都是动态大小类型，通常通过引用使用。

这里的 **C 字符串指一种数据约定：从起始地址读取字节，遇到第一个`0`字节就结束**。
