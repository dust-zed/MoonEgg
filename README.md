# MoonEgg

MoonEgg 是一个 **Android 优先、Rust 驱动**的媒体播放引擎。

项目以学习音视频开发、Rust 系统编程和完成职业转型为目标，但会按照正式开源项目的标准持续建设：明确边界、测试先行、记录设计决策、提供可运行示例，并以可观测的性能和稳定性指标验收。

## 项目方向

- Android 是第一个完整支持的平台，Kotlin 负责应用层，Rust 负责播放内核。
- 先完成音频，再完成视频；先保证正确，再优化性能。
- 先支持本地、无加密、可 seek 的媒体文件，再考虑网络流、字幕和 DRM。
- 不重复制造成熟编解码器，重点掌握容器、时间戳、缓冲、线程、音画同步、FFI 和平台输出。

第一阶段的完整作品目标是：在 Android 真机上稳定播放本地 H.264/AAC MP4，支持 prepare、play、pause、seek、stop，具备音画同步、生命周期处理、错误上报和基础性能指标。

## 当前阶段

项目处于规划阶段。开发顺序、里程碑、学习目标、验收指标和开源规范见 [项目计划](docs/PROJECT_PLAN.md)。

## 暂不承诺

- HLS / DASH 和直播
- DRM
- 投屏、后台播放和播放列表
- 自研音视频编解码器
- iOS、桌面端和 Web 平台

这些能力只有在本地播放主链路稳定、可测试且有性能基线后才会进入路线图。
